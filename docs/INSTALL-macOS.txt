MALON FREQUENCY ANALYZER 1.1 - macOS (VST3 + AU, Apple Silicon + Intel)

1. Unzip this file.
2. Copy  VST3/Malon Frequency Analyzer.vst3
   to    ~/Library/Audio/Plug-Ins/VST3/
   (In Finder: Go > Go to Folder... and paste ~/Library/Audio/Plug-Ins/VST3 . Create the folder if needed.)
   Logic / GarageBand: also copy AU/Malon Frequency Analyzer.component
   to    ~/Library/Audio/Plug-Ins/Components/
3. This test build is NOT signed by Apple, so macOS may say it "is damaged" or
   "cannot be opened". Fix it ONE of these ways:
   a) Terminal (most reliable):
        xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Malon Frequency Analyzer.vst3"
        xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"Malon Frequency Analyzer.component"
   b) Open your DAW once, then go to System Settings > Privacy & Security,
      scroll down and click "Open Anyway" next to Malon Frequency Analyzer, then reopen the DAW.
4. Rescan plugins in your DAW (FL Studio: Options > Manage plugins > Find installed plugins).

Tips: M = meters on/off, F = freeze, R = reset. Hover the graph to read frequency and level.
The channel menu (top bar) switches Stereo / Left / Right / Mix / Mid / Side.
